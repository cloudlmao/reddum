## What Makes It Fun

**Combo System** — Kill fast, earn more. Chain kills to rack up multipliers and bonus gold. The faster you clear, the richer you get.

**Tower Synergies** — Freeze enemies with Cryo, then melt them with a Beam Array. Drop a Shock Trap on frozen clusters. Every tower combination opens new strategies.

**Path Traps** — Place Blight Traps and Shock Traps directly on enemy paths. Watch entire waves walk into your kill zones.

| Feature | Description |

## Towers

| Tower | Role | What It Does |
|-------|------|--------------|
| **Sentry** | Starter | Reliable all-rounder. Cheap and effective. |
| **Marksman** | Sniper | Massive single-target damage. Limited placement. |
| **Gatling** | Crowd Control | High fire rate shreds swarms. |
| **Cryo Tower** | Utility | Freezes enemies. Pairs with everything. |
| **Mortar** | AoE | Explosive splash damage. Essential for groups. |
| **Beam Array** | Sustained DPS | Continuous damage that melts tanks. |
| **Blight Trap** | Path DoT | Toxic field poisons all who pass through. |
| **Shock Trap** | Path Burst | Chain lightning fries clustered enemies. |

## Enemies

| Enemy | Threat Level | Behavior |
|-------|--------------|----------|
| **Grunt** | Basic | Fodder. Die in droves. |
| **Dasher** | Fast | Speed demon. Low HP, hard to track. |
| **Juggernaut** | Tank | Massive HP pool. Slow but unstoppable. |
| **Overlord** | Boss | Wave boss. Focus fire required. |
| **Hatchling** | Swarm | Overwhelming numbers. |
| **Mender** | Support | Heals nearby enemies. Priority target. |
| **Sentinel** | Defensive | Shield absorbs hits. Break it first. |
| **Hydra** | Splitter | Splits into smaller enemies on death. |
| **Speeder** | Accelerating | Gets faster as it moves. |

## Difficulty Modes

- **Easy** — Learn the ropes. Fewer waves, forgiving scaling.
- **Medium** — The intended experience. Enemy types unlock gradually.
- **Hard** — More enemies, faster spawns, tougher bosses. Bring strategy.
- **Endless** — No final wave. Survive until you can't.

## Controls
|--------|-------|
| Select tower from shop | `1-8` or click shop |
| Place tower | Left click |
| Select placed tower | Left click on tower |
| Upgrade tower | Click upgrade buttons |
| Move tower | Drag (between waves only) |
| Cancel | Right click or `ESC` |
| Fast forward | `Space` |
| Pause | `ESC` |
