---

## Features

- **6 Tower Types**: Sentry, Railgun, Cryo, Beam Array, Cannon towers with unique abilities
- **3 Enemy Types**: Grunt, Swarmling, and Juggernaut enemies with distinct behaviors
- **10 Progressive Waves**: Increasingly challenging enemy compositions

---

## How to Play

| Control | Action |
|---------|--------|
| `1`, `2`, `3` | Select tower type |
| `Left Click` | Place tower |
| `Right Click` | Deselect tower |
| `Space` | Start next wave |
| `Escape` | Pause/Resume |
